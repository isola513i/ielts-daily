# IELTS Daily

เว็บฝึกคำศัพท์ IELTS General สำหรับคนไทย ใช้บนมือถือเป็นหลัก มีคำและวลี 150 ใบ พร้อมชนิดคำ นิยามอังกฤษ คำแปลไทย ตัวอย่าง และเสียงอ่านจากเบราว์เซอร์

**เว็บไซต์:** https://isola513i.github.io/ielts-daily/

## ใช้งาน

1. กด **เริ่มฝึก 10 คำ** หรือเลือกหมวดที่อยากฝึก
2. ลองนึกความหมาย กดฟังคำศัพท์ แล้วเปิด **ดูเฉลย**
3. อ่านนิยาม คำแปล และประโยคตัวอย่าง เลือก **จำได้** หรือ **ยังจำไม่ได้** ตามจริง
4. คำที่ยังจำไม่ได้จะวนกลับมา โดยแต่ละคำแสดงรวมไม่เกิน 3 ครั้งต่อรอบ
5. เปลี่ยน American / British / Australian ได้ใน **ตั้งค่า** และกลับมาฝึกต่อรอบเดิมได้

เสียงที่ใช้ได้และความเป็นธรรมชาติขึ้นกับเครื่องและเบราว์เซอร์ หากไม่มีเสียงตรงสำเนียง เว็บจะแจ้งให้ทราบโดยไม่สลับสำเนียงเอง ไม่มีการเรียกบริการเสียงที่คิดเงิน เว็บไม่รับรองว่าเสียงจะครบทุกสำเนียงหรือทำงานออฟไลน์ได้ทุกเครื่อง

ความคืบหน้าเก็บใน `localStorage` ของเบราว์เซอร์นี้เท่านั้น ไม่ส่งขึ้น GitHub หรือเซิร์ฟเวอร์ ไม่ซิงก์ข้ามอุปกรณ์และจะหายหากล้างข้อมูลเว็บไซต์ หากระบบบันทึกถูกบล็อก เว็บยังใช้ฝึกในรอบที่เปิดอยู่ได้

## เปิดในเครื่อง

ใช้ Python 3 สำหรับพรีวิว และ Node.js 22 ขึ้นไปสำหรับการทดสอบ (CI ใช้ Node 24)

```sh
npm run dev
```

เปิด http://127.0.0.1:4173/ ไม่ต้องติดตั้ง dependencies เพื่อใช้งานเว็บ เพราะ runtime เป็น HTML/CSS/JavaScript ล้วน

## ทดสอบ

```sh
npm ci
npm test
npx playwright install chromium webkit
npm run test:browser
```

Unit tests ตรวจคิวฝึก ข้อมูลคำศัพท์ storage และการเลือกเสียง ส่วน browser tests ใช้ WebKit จำลอง iPhone และ Chromium บนเดสก์ท็อป รวมถึงตรวจ accessibility อัตโนมัติด้วย axe-core และทดสอบ asset ภายใต้ path `/ielts-daily/`

สำหรับภาพหน้าจอ ให้เปิดพรีวิวก่อน แล้วรัน `node tests/capture.mjs` ผลอยู่ใน `.impeccable/review/` การจำลอง WebKit ไม่ใช่การฟังเสียงหรือทดสอบ VoiceOver บน iPhone จริง

## โครงสร้าง

- `web/` เป็นไฟล์ที่เผยแพร่ทั้งหมด ไม่มีขั้นตอน build
- `web/js/vocabulary.js` เก็บเนื้อหาหนึ่งความหมายต่อการ์ด และหมวดคำศัพท์
- `web/js/session.js`, `storage.js`, `speech.js` จัดการคิวฝึก การบันทึก และเสียง
- `web/js/app.js` จัดการหน้าจอและ hash navigation
- `tests/` เป็น unit tests และ browser acceptance tests
- `docs/` เก็บแบบ แผน ADR และ glossary

เมื่อแก้ชุดคำศัพท์ ให้คงลำดับแถวเดิมไว้ เพราะรหัสการ์ดอ้างอิงหมวดและลำดับ ไม่ควรสลับลำดับการ์ดเดิมโดยไม่ทำ migration

## เผยแพร่

GitHub Actions ตรวจ tests ก่อนอัปโหลด `web/` และเผยแพร่ผ่าน GitHub Pages เมื่อไฟล์เว็บ ระบบทดสอบ หรือ workflow ใน branch `main` เปลี่ยน ส่วนการแก้เอกสารอย่างเดียวไม่ทำให้ deploy ซ้ำ ใช้โดเมน `github.io` และ repository สาธารณะตามแผนที่เลือก ไม่มี custom domain หรือบริการ Backend

เนื้อหาคำศัพท์และประโยคตัวอย่างเขียนขึ้นสำหรับโครงการนี้ ไม่ใช่ชุดข้อสอบทางการ และจำนวนคำที่จำได้ไม่ใช่การคาดการณ์คะแนน IELTS
