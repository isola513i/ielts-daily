# Glossary

| Term | Meaning in this project |
| --- | --- |
| Card / การ์ด | One English word or phrase, one part of speech and one meaning, with a definition, Thai translation and English example. |
| Topic / หมวด | A group of 30 related cards. |
| Session / รอบฝึก | A round starting with 10 unique cards. Missed words can re-enter the same queue. |
| Presentation / การแสดงการ์ด | One opportunity to recall and answer a card. A card has at most three presentations per round. |
| Remembered / จำได้ | The learner's latest answer says they recalled the meaning. This is not a permanent mastery rating. |
| Needs practice / ยังจำไม่ได้ | The latest answer says the learner needs another attempt. |
| Review / ทบทวน | Seeing a missed word again at the tail of the queue, or practising it in a later session. No date-based scheduling in v1. |
| Accent / สำเนียง | One requested locale: American en-US, British en-GB or Australian en-AU. |
| Voice / เสียง | A speech-synthesis voice provided by the browser/device with an actual matching locale. |
| Literal translation | Word-by-word translation, deliberately excluded after clarification. Thai translations express the taught sense naturally. |
| Progress / ความคืบหน้า | Latest answers and unfinished session stored in the current browser. |
